# RMBench Results Directory

This directory stores benchmark evaluation results. All files here are generated by running the benchmark — no pre-generated data is committed to the repository.

## Structure

```
results/
|-- README.md                                    # This file
|-- <model>_none_<timestamp>.json               # Per-model per-run results
|-- rmbench_results_<timestamp>.json            # Merged results across all models
|-- comparison_table_<timestamp>.csv            # Per-model metric comparison (for paper tables)
`-- figures/                                     # Generated visualizations (PNG)
    |-- attack_success_rates.png
    |-- model_comparison_heatmap.png
    |-- defense_effectiveness.png
    `-- ...
```

## Generating Results

```bash
# Baseline evaluation (no defense) — all 6 models, 10 samples per attack-task combo
python run_benchmark.py --defenses none --samples 10

# Ollama models only (no API keys needed)
python run_benchmark.py \
  --models mistral:7b gemma3:4b deepseek-r1:7b \
  --defenses none --samples 10

# With defense methods
python run_benchmark.py \
  --defenses none context_sanitization injection_detection \
  --samples 10

# Generate visualizations from existing results
python scripts/generate_visualizations.py
```

## Metric Interpretation

| Metric | Range | Direction | Good Value |
|--------|-------|-----------|------------|
| ASR (Attack Success Rate) | 0.0–1.0 | Lower is better | < 0.25 |
| CRI (Context Robustness Index) | 0.0–1.0 | Higher is better | > 0.75 |
| GPS (Goal Preservation Score) | 0.0–1.0 | Higher is better | > 0.80 |
| Truthfulness | 0.0–1.0 | Higher is better | > 0.80 |
| Tool Safety | 0.0–1.0 | Higher is better | > 0.85 |
| Memory Integrity | 0.0–1.0 | Higher is better | > 0.80 |

## Loading Results in Python

```python
from rmbench.utils.result_utils import load_results, results_to_dataframe

# Load a single result file
data = load_results("results/mistral_7b_none_20260626_120000.json")
print(data["metrics"])  # {'asr': 0.33, 'cri': 0.77, ...}

# Convert to DataFrame for analysis
df = results_to_dataframe(data)
print(df[["task_type", "attack_type", "attack_successful", "task_score"]].describe())

# Compare multiple runs
from rmbench.utils.result_utils import merge_results

merged = merge_results([
    "results/mistral_7b_none_*.json",
    "results/gemma3_4b_none_*.json",
])
print(merged["metrics"])
```
